🔒 1. Information Security & The CIA Triad Core Foundation

Information Security is the practice of protecting information and information systems from unauthorized access, use, disclosure, disruption, modification, or destruction. It safeguards both digital and physical data assets across three universally recognized pillars known as the CIA Triad:

🔐

Confidentiality

Ensures that sensitive data is accessible only to authorized personnel and concealed from unauthorized entities, processes, or devices.

Key Controls: AES-256 encryption at rest/in transit, Role-Based Access Control (RBAC), multi-factor authentication, data classification.
⚠️ Threat: Eavesdropping, network packet sniffing, credential harvesting breaches.
🛡️

Integrity

Guarantees that data remains accurate, complete, and protected against unauthorized modification, insertion, or deletion throughout its entire lifecycle.

Key Controls: Cryptographic hashes (SHA-256), Digital Signatures (RSA/ECDSA), Message Authentication Codes (HMAC), write-blocking.
⚠️ Threat: Man-in-the-Middle payload tampering, unauthorized database updates, audit record falsification.
⚡

Availability

Ensures that systems, networks, applications, and data are dependable and readily accessible to authorized users whenever required for legitimate operations.

Key Controls: Redundant server clusters, automated failover (RAID), DDoS mitigation scrubbing, immutable offline backups (3-2-1 rule).
⚠️ Threat: Ransomware data lockouts, volumetric DDoS floods, environmental hardware outages.
Extended Principles to Know for Viva: Beyond the CIA triad, rigorous security architectures enforce Authenticity (verifying the true identity of a communicating party), Non-Repudiation (ensuring a sender cannot deny having sent a message, achieved via asymmetric digital signatures), and Accountability (traceable audit logging).
⚡ 2. Threats, Vulnerabilities & Attack Classifications Threat Landscape

👁️ Passive Attacks

Passive attacks aim to obtain or monitor transmitted data without modifying system resources or altering message content. The target system continues operating normally, making detection through logs extremely difficult.

  • Release of Message Contents: Eavesdropping on unencrypted conversations, emails, or file transfers over insecure lines.
  • Traffic Analysis: Observing communication patterns, frequency, burst length, and IP packet flows even when content is encrypted to deduce relationships or organizational actions.
Primary Defense: Robust End-to-End Encryption (TLS 1.3, IPSec).

💥 Active Attacks

Active attacks involve the alteration of data stream or the creation of a fraudulent stream. They directly disrupt operations or compromise integrity and availability.

  • Masquerade: An entity pretends to be a different entity (e.g. IP/ARP spoofing, identity theft).
  • Replay: Passive capture of a valid authentication token or message followed by re-transmission to gain unauthorized authorization.
  • Modification of Messages: Altering legitimate data in transit or delaying message delivery.
  • Denial of Service (DoS): Overwhelming server resources to deny legitimate user access.
Primary Defense: Intrusion Detection/Prevention, cryptographic nonces, MFA, and integrity checks.

Core Attack Classifications

1. Interception (Confidentiality) An unauthorized party gains access to an asset (e.g. wiretapping, packet sniffing).
2. Interruption (Availability) An asset of the system becomes lost, unavailable, or unusable (e.g. cutting cables, DoS flood).
3. Modification (Integrity) An unauthorized party tampers with an asset (e.g. changing values in a bank database).
4. Fabrication (Authenticity) An unauthorized party inserts counterfeit objects into the system (e.g. forged DNS records, bogus transactions).

🦠 3. Malicious Code Taxonomy Malware Analysis

Malware refers to any software intentionally designed to cause disruption, damage, or unauthorized access to a computer, server, client, or network. Understanding propagation mechanics is crucial for defense:

🧬

Computer Virus

A piece of code that attaches itself to a host executable program or document. When the host program runs, the virus executes, infects other files, and delivers its payload. It requires user interaction (launching the infected program) to spread.

Host DependentUser TriggeredFile Infector
🐛

Computer Worm

A standalone, self-replicating program that propagates across local networks and the internet without human intervention. Worms exploit unpatched network daemon vulnerabilities (e.g. buffer overflows, SMB weaknesses) to spread autonomously at machine speed.

StandaloneAutonomousNetwork Propagating
🐴

Trojan Horse

Malware disguised as useful, legitimate, or benign software (such as a game, utility, or invoice attachment). Unlike viruses, Trojans do not replicate or infect other files; instead, they stealthily install backdoors, keyloggers, or downloader payloads once executed.

DeceptiveNon-ReplicatingBackdoor Dropper
💰

Ransomware

Malicious software that denies access to files or systems by encrypting them using strong asymmetric/symmetric cryptographic algorithms (e.g. AES-256 + RSA-2048) and demands extortion payment (typically in Bitcoin) in exchange for the decryption key.

ExtortionCrypto-LockAvailability Attack
🕵️

Spyware & Keyloggers

Software secretly installed on a victim's machine to covertly record keystrokes, browser history, microphone inputs, and application usage, transmitting stolen credentials back to an attacker's command-and-control (C2) server.

Stealth ReconCredential TheftC2 Exfiltration
🤖

Botnets & Rootkits

Rootkits operate at kernel or hypervisor levels to hide processes and network sockets. Botnets are networks of compromised machines ("zombies") controlled collectively by a botmaster to execute massive distributed denial-of-service (DDoS) attacks.

🛡️ 4. Network Security: Firewalls & Intrusion Detection Systems (IDS) Perimeter Defense

🔥 Firewalls: The Perimeter Guard

A firewall is a network security device that monitors and filters incoming and outgoing network traffic based on predetermined organizational security rules. It acts as a defensive barrier between an untrusted network (the Internet) and a trusted private network.

  • Stateless Packet Filtering (Layer 3/4): Examines individual packet headers (Source IP, Destination IP, Protocol, Port number) independently without tracking connection context.
  • Stateful Inspection (Layer 4): Tracks active TCP handshakes and state tables (SYN, SYN-ACK, ESTABLISHED), blocking unsolicited inbound packets that do not correspond to an established internal request.
  • Next-Generation Firewall (NGFW / Layer 7): Performs Deep Packet Inspection (DPI) to inspect application-layer payloads, detecting malicious traffic masquerading on standard ports (like HTTP/80).

🚨 Intrusion Detection Systems (IDS): The Security Alarm

An Intrusion Detection System (IDS) analyzes network traffic or system logs to detect unauthorized activity or security policy violations, generating alerts for security analysts. Unlike firewalls, standard IDS sensors sit out-of-band and do not sit directly in the traffic flow.

  • NIDS (Network IDS): Monitors traffic traversing subnet choke points via SPAN/mirror ports (e.g. Snort, Zeek, Suricata).
  • HIDS (Host IDS): Monitors log files, registry changes, process execution, and critical system file integrity on an individual host (e.g. OSSEC, Wazuh).
  • Signature-Based Detection: Matches bytes against known exploit signatures. Highly accurate for known threats; blind to zero-day exploits.
  • Anomaly-Based Detection: Builds a statistical baseline of normal behavior and alerts on statistical deviations. Capable of catching zero-days, but prone to false-positive alarms.

🔑 5. Defensive Password Security & Safe Authentication Defensive Engineering

Password Cracking Risks

Attackers exploit weak passwords through automated computational techniques:

  • Brute-Force Attack: Systematically attempting all possible character permutations until the correct string is discovered. Exponentially difficult as length increases.
  • Dictionary Attack: Testing words from curated wordlists (e.g. RockYou) with common leetspeak substitutions (e.g. P@ssw0rd1).
  • Rainbow Table Attack: Using precomputed lookup tables of plaintext-to-hash mappings to reverse unsalted cryptographic hashes in seconds.
  • Credential Stuffing: Automated injection of stolen username/password combinations leaked from external breaches into other services.

Defensive Architectural Controls

How modern systems protect authentication credentials:

  • Cryptographic Salting: Appending a unique, random string (salt) to each password before hashing. This renders precomputed Rainbow Tables completely useless, as every user has a unique salt.
  • Slow Key Derivation Functions: Algorithms like Argon2id, bcrypt, and PBKDF2 incorporate configurable work factors and memory hardness, making GPU/ASIC cracking cost-prohibitive.
  • Multi-Factor Authentication (MFA): Combining three distinct factors: Something you know (password), Something you have (hardware security key, TOTP app), and Something you are (biometrics).
  • Rate Limiting & Lockout: Enforcing exponential backoff after consecutive failed authentication attempts.
Insecure Connections & Public Wi-Fi Risks: Transmitting credentials over plaintext HTTP or unencrypted public Wi-Fi exposes sessions to Man-in-the-Middle (MITM) packet sniffing and SSL stripping. Modern web standards require HTTPS (TLS 1.3), which pairs asymmetric key negotiation with symmetric AES payload encryption, verified through trusted Certificate Authorities (CAs).
⚠️ 6. Case Study: WannaCry Ransomware Outbreak (May 12, 2017) Syllabus Case Study
Global Incident Analysis

WannaCry: When a Weaponized Exploit Met Obsolete Legacy Systems

On Friday, May 12, 2017, the WannaCry (WanaCrypt0r 2.0) ransomware outbreak erupted globally. Within 48 hours, it paralyzed over 200,000 computers across 150+ countries, becoming one of the most destructive and fast-moving cyberattacks in history.

Exploit & Attack Vector:

WannaCry combined ransomware with a self-propagating worm. It exploited EternalBlue (CVE-2017-0144), a vulnerability in Microsoft's Server Message Block version 1 (SMBv1) protocol that had been leaked by the mysterious group "The Shadow Brokers" in April 2017. Once inside a network, the malware installed the DoublePulsar backdoor, injected shellcode, and scanned TCP port 445 on local subnets and random public IP ranges to infect adjacent machines without user intervention.

Critical Impact:

In the United Kingdom, the National Health Service (NHS) suffered devastating disruption: 80 out of 236 NHS hospital trusts were crippled, over 19,000 medical appointments and surgeries were cancelled, and emergency ambulances had to be diverted. Global logistics firm FedEx, Spanish telecom Telefónica, automotive giant Renault (which halted manufacturing in French plants), and Deutsche Bahn were severely impacted. Victims were confronted with a red countdown UI demanding $300 to $600 in Bitcoin.

The Accidental Kill Switch:

British cybersecurity researcher Marcus Hutchins (@MalwareTechBlog) analyzed a WannaCry binary sample and noticed an unusual hardcoded query to an unregistered domain: www.iuqerfsodp9ifjaposdfjhgosurijfaewrwergwea.com. The malware queried this domain before executing; if the domain resolved (was live), the malware terminated execution (an anti-sandbox evasion tactic). Hutchins registered the domain for $10.69 to sinkhole telemetry, which inadvertently triggered the global kill switch and halted worm propagation.

Key Organizational Lessons & Preventive Controls:

  • Timely Patch Management: Microsoft had published security bulletin MS17-010 fixing the EternalBlue flaw on March 14, 2017—nearly two full months before the attack! Organizations that had implemented regular patch cycles were completely immune.
  • Deprecating Obsolete Protocols: SMBv1 is an insecure 30-year-old protocol. Organizations must disable legacy protocols and block sensitive management ports (such as TCP port 445) at the internet perimeter.
  • Operating System Lifecycle: Unsupported operating systems (Windows XP, Windows Server 2003) no longer received routine security updates. Microsoft was forced to take the extraordinary step of issuing an emergency out-of-band patch for discontinued OS versions.
  • Immutable 3-2-1 Backups: The only sure recovery from ransomware without paying extortion is restoring from verified backups. Organizations must maintain 3 copies of data on 2 different media, with at least 1 copy stored offline, air-gapped, or immutable.
  • Network Micro-Segmentation: Flat internal networks allowed the worm to spread laterally between departments; segmented network zones prevent lateral contagion.

Q1 Which security objective of the CIA triad is violated when an unauthorized user modifies the account balance in a banking database?
Explanation: Integrity guarantees that information and systems are accurate, complete, and protected against unauthorized modification or tampering. Unauthorized modification of account records directly violates data integrity.
Q2 What is the fundamental operational difference between an active attack and a passive attack?
Explanation: Passive attacks (e.g. packet sniffing, traffic analysis) monitor or intercept data without altering system state, making detection difficult. Active attacks (e.g. masquerading, message modification, DoS) directly alter data or disrupt operations.
Q3 How does a computer worm primarily differ from a traditional computer virus?
Explanation: A virus must attach to an executable file and requires a user to run the host program. A worm is an independent program that exploits network daemon vulnerabilities to replicate and spread across machines without user action.
Q4 In social engineering, how does generative AI voice cloning impact traditional telephone-based verification?
Explanation: Synthetic voice cloning exploits the human layer of authentication. By accurately mimicking trusted colleagues or executives, attackers create artificial urgency to bypass procedures and obtain unauthorized credentials or fund transfers.
Q5 What is the key functional difference between a standard perimeter Firewall and an Intrusion Detection System (IDS)?
Explanation: A firewall sits in-line at the network boundary to allow or deny traffic based on IP/port/state rules. An IDS sits out-of-band to inspect packet payloads for attack signatures or anomalies and raises alerts for human review.
Q6 What is a major advantage of anomaly-based intrusion detection over signature-based intrusion detection?
Explanation: Signature-based systems require a known pattern in their database, making them blind to zero-days. Anomaly-based systems model normal behavior and flag deviations, allowing them to detect novel or zero-day threats (at the trade-off of higher false alarm rates).
Q7 Why is cryptographic salting critical when storing password hashes in a database?
Explanation: A salt is a unique random string appended to each password. Because every user has a different salt, identical passwords yield different hashes, completely neutralizing precomputed lookup dictionaries and Rainbow Table attacks.
Q8 Which vulnerability enabled the WannaCry ransomware worm to propagate rapidly across networks in May 2017?
Explanation: WannaCry utilized the EternalBlue exploit (CVE-2017-0144) targeting an unpatched flaw in Microsoft's SMBv1 protocol on port 445, spreading autonomously between connected network devices.
Q9 How was the rapid propagation of the WannaCry ransomware temporarily halted worldwide on May 12, 2017?
Explanation: Researcher Marcus Hutchins identified a hardcoded query to an unregistered domain in the binary. Upon registering the domain, requests began returning active HTTP responses, which caused the malware's evasion check to terminate execution.
Q10 What is the single most important administrative lesson from the WannaCry incident regarding enterprise patch management?
Explanation: Microsoft had published security patch MS17-010 on March 14, 2017. Organizations that instituted regular, structured patch management were fully protected when the outbreak hit in May 2017.
