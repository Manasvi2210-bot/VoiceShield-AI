📦 Cryptographic File Integrity Checker

Defensive utility to compute streaming SHA-256 cryptographic digests, verify software downloads against publisher reference hashes, and detect file tampering or corruption.

🔒
Defensive Safety & Integrity Principles:
  • Streaming Execution: Files are read in fixed 64 KB memory chunks using Python’s standard library hashlib and immediately purged from disk upon computation. Uploaded files are never executed, unpacked, or opened as active content.
  • Integrity vs. Authenticity: A matching hash verifies bit-for-bit consistency with your reference value (proving the file has not been altered in transit). However, it does not guarantee that the software is benign or malware-free unless the reference hash was obtained from a verified, trusted publisher.

Classroom Verification Concepts

The Avalanche Effect: Changing a single bit in a 10 GB file completely randomizes the computed SHA-256 output digest.

Collision Resistance: SHA-256 provides 256 bits of cryptographic security; finding two different files with the same SHA-256 digest is computationally infeasible.
